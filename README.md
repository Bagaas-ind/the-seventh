## 📖 Tentang Proyek
Ini adalah website profil resmi untuk band **The Seventh**. Dibangun dengan pendekatan *Dark Mode* dan tipografi tebal yang kuat untuk merepresentasikan energi dari musik Rock/Metal Alternatif. 

Aplikasi ini menggunakan **arsitektur Decoupled (Headless)**, di mana Backend (Laravel) menyediakan REST API untuk manajemen konten, dan Frontend (React) menampilkannya dengan antarmuka yang interaktif.

## ✨ Fitur Utama
- 🎨 **UI/UX Modern:** Desain *dark-mode* dengan aksen merah darah (Blood Red).
- 📱 **Responsif:** Tampilan optimal di perangkat mobile, tablet, dan desktop.
- 🎸 **Landing Page Interaktif:** Hero section dramatis, profil band, jadwal tur, dan integrasi YouTube.
- 🔐 **Autentikasi Admin:** Sistem login aman menggunakan Token (Laravel Sanctum).
- 📰 **Dashboard Admin:** Panel untuk mengelola data Berita, Tur, Musik, dan Galeri.

## 🛠️ Teknologi yang Digunakan
**Backend:**
- Laravel 11 (REST API)
- MySQL
- Laravel Sanctum

**Frontend:**
- React.js (Vite)
- Tailwind CSS
- React Router DOM
- Axios
