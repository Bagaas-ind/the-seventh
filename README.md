# THE SEVENTH

Website profil band Rock/Metal Alternatif bernama **The Seventh**. 
Dibangun menggunakan arsitektur Decoupled (Backend & Frontend terpisah) dengan tema Dark & Edgy.

## 🛠️ Teknologi
*   **Backend:** Laravel 11, MySQL, Sanctum
*   **Frontend:** React (Vite), Tailwind CSS, Axios

## 🚀 Cara Menjalankan
1. Jalankan Backend: `cd the-seventh-api` -> `php artisan serve`
2. Jalankan Frontend: `cd the-seventh-web` -> `npm run dev`
